# 短代碼固定頁面的 Yoast SEO 操作

更新日期：2026-10-02

## 先說結論

頁面只放 `[bfnd_page key="..."]` 不會妨礙 Google 收錄：前台會把短代碼轉成完整 HTML。問題在於 Yoast 後台原先只分析 WordPress 編輯器看得到的短代碼，沒有讀到存在「網站版面」設定中的真正標題、段落與卡片內容。

外掛來源 `0.5.8` 已用 Yoast 官方內容分析擴充介面，把儲存後的版面內容提供給 Yoast；前台標題與搜尋摘要也改由 Yoast 單一管理，避免網站模板再輸出第二組重複的 `<title>`／description。

## 八個固定版面頁怎麼編輯

1. WordPress 後台 → **網站版面** → 選擇要優化的頁面。
2. 修改頁面文案後，在同頁 **SEO｜搜尋結果資訊** 區填：
   - **SEO 標題**：頁面主題＋品牌名，讓搜尋結果一眼看懂內容。
   - **Meta Description**：用一至兩句準確描述頁面內容與訪客可採取的動作；每頁寫自己的摘要。
   - **Yoast 焦點關鍵字詞**：放一個主要搜尋詞組，供 Yoast 做檢查，不會直接顯示給訪客或搜尋引擎。
3. 儲存網站版面，再點同頁的 **開啟 WordPress 頁面編輯器查看 Yoast 分析**。Yoast SEO／可讀性分析此時會讀到最新已儲存版面。若文字剛在網站版面更新，先儲存再重新載入頁面編輯器。
4. 分享圖請在 WordPress 頁面編輯器設定**精選圖片**；有不同的 Facebook／X 分享素材時，再到 Yoast 的社群分享欄指定。
5. 正式部署後，查看頁面原始碼，確認只有一個 title、一個 meta description、一個 canonical，並檢查 `og:title`、`og:description`、`og:image`。

## Yoast 燈號怎麼看

- Yoast 紅／橘／綠燈是編輯檢查提示，不是 Google 排名分數，也不能保證收錄或排名。
- 中文文章可讀性檢查未必能準確評估語意；先確保標題清楚、段落短、資訊正確和連結好用，不要為了全綠改壞品牌文字。
- SEO 標題及摘要要避免多頁共用。不要在正文反覆堆關鍵字；焦點關鍵字詞僅用來檢查頁面是否聚焦。
