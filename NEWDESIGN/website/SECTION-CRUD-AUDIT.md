核對日期：2026-09-18。範圍：八個 `[bfnd_page]` 頁面，以及 WooCommerce 的商店、購物車、會員流程。0.5.1 外掛／1.2.3 主題已由 WordPress 後台回報更新成功；飛熊日誌及其三篇示範文章已在正式站驗證。下表的其他小項目管理缺口仍待處理。

### 2026-10-05 Banner 圖片管理新增能力

- 後台「網站版面 → Banner 輪播」為首頁、家具、生活木作、木作學堂、合作提案提供獨立媒體庫圖片清單；每組可保留 1–10 張，新增／移除及逐張前後排序後一次儲存。此 CRUD 範圍只涵蓋五個固定主視覺照片，不改變頁面其他固定區塊或文字欄位能力。
- 主題 `1.3.28` 載入輪播樣式與操作；外掛 `0.5.29` 保存媒體附件 ID 並提供管理介面。前台自動輪播、前後控制及暫停。五頁後台各顯示 3 張，正式站逐頁切換與首頁自動切換已覆驗。

## 結論

目前**不是每頁每個小區塊都有 CRUD**。固定版型會自動列出頂層區塊的文字、圖片與「隱藏整個區塊」欄位，但連結目的地未列入通用編輯欄位。客戶明確要求版面段落及數量完全遵照手稿，因此通用「新增區塊」已從本地修正移除。隱藏頂層區塊也不等於刪除其內的單一卡片。

## 客戶可自由編輯的完成標準

1. 對手稿既有的**內容集合**使用與圖稿相符的原生文章資料：在所屬清單新增、檢視、修改、移到回收桶／還原；每筆設定標題、內文、精選圖片、分類與發布狀態。固定數量的手稿卡片不新增未畫出的項目。
2. 固定英雄區、單一 CTA 與表單外框保留版型控制；提供文字、圖片、顯示開關。未獲客戶修改手稿時，不新增另一段或改變位置。
3. 家具作品、生活木作作品、課程、日誌、商品繼續使用 WordPress／WooCommerce 既有內容類型，不在「網站版面」再造第二套重複資料。
4. 每頁主編輯區維持一行短代碼。後台逐筆操作需實測草稿／公開、前台位置與樣式、回收桶／還原、手機版、權限與 nonce；八頁及商務路由需回歸檢查。

目前不能向客戶宣稱「每個小區塊都有完整 CRUD」。

### Maker 導覽紅筆註記（2026-09-30）

`生活木作版型.png` 與 `木作學堂頁面-實體跟線上課.png` 將頁首導覽的 Maker 工藝基地劃除。本次從新版外掛與主題的共用頁首移除右側 Maker 連結；頁尾 Maker 資訊及品牌故事內文的 Maker 基地段落保留，因圖稿未劃除這兩處。原始碼版本已升至外掛 0.5.2、主題 1.2.4；正式站仍需部署後即時確認。

後台「網站版面」的單頁 CRUD 只會從各頁主內容產生文字、圖片與區塊顯示欄位，不包含全站共用頁首或頁尾，因此原本就不會為頁首 Maker 連結產生孤立欄位。管理頁現在明示此範圍，並提供品牌故事版面管理連結：故事內文的 Maker 段落仍可編輯或隱藏；頁尾 Maker 仍是共用固定版面，不會出現在單頁欄位中。後台版面頁 CSS／JS 的快取版本同步升至 0.5.2。

### 後台 CRUD 結論補充

通用「網站版面」目前依頁面輸出的 HTML 擷取既有文字／圖片欄位，並提供頂層區塊隱藏；欄位以 `section_1_text_1` 這類順序索引命名，HTML 結構或前方區塊變動時，索引有漂移風險。連結目的地不是通用編輯欄位。它適合微調既有固定版型內容，不是可以管理任意重複集合的內容型 CRUD。家具作品、課程、生活木作作品、日誌及詢問紀錄則分別透過原生內容類型管理，兩種能力不要混為一談。

### 數量彈性需列為需求變更

本文件 2026-09-18 的客戶要求紀錄是「手稿既有區塊及項目數固定」。本次討論中的規劃方向則是維持頂層版面與排序，讓區內重複項目可以新增、編輯、排序及移至回收桶／還原。若採此方向，必須把項目數量彈性列為相對於原紀錄的需求變更；本文件記錄規劃差異，不代表客戶已核准該變更。
