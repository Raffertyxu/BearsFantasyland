# NEWDESIGN 小區塊 CRUD 核對

核對日期：2026-09-18。範圍：八個 `[bfnd_page]` 頁面，以及 WooCommerce 的商店、購物車、會員流程。0.5.1 外掛／1.2.3 主題已由 WordPress 後台回報更新成功；飛熊日誌及其三篇示範文章已在正式站驗證。下表的其他小項目管理缺口仍待處理。

## 結論

目前**不是每頁每個小區塊都有 CRUD**。固定版型會自動列出頂層區塊的文字、圖片與「隱藏整個區塊」欄位，但連結目的地未列入通用編輯欄位。客戶明確要求版面段落及數量完全遵照手稿，因此通用「新增區塊」已從本地修正移除。隱藏頂層區塊也不等於刪除其內的單一卡片。

| 分頁 | 已能逐筆新增、編輯、刪除的資料 | 仍缺少區內小項目的完整 CRUD |
| --- | --- | --- |
| 首頁 | 家具精選讀取「家具作品」文章；日誌讀取 WordPress 原生文章 | 五項理念、家具／學堂導流卡、合作卡片無同款新增、逐張移除與排序 |
| 家具作品 | 家具文章及分類可由 WordPress 文章類型／分類新增、修改、移除；卡片自動顯示 | 主視覺與訂製 CTA 為固定版型，只能修改欄位或隱藏頂層段；不能從此頁新增同款版型段 |
| 生活木作 | 作品由「生活木作」文章類型逐筆管理；版面有顯示作品開關 | 四個未來系列方向、四個製作步驟無區內同款新增、逐筆隱藏／移除與排序 |
| 木作學堂 | 正式課程由「木作課程」文章類型逐筆管理 | 四個學習特色寫死；尚未有線上課程時的預告卡與通知卡寫死，不能逐張 CRUD |
| 品牌故事 | 固定文字與圖片可在版面欄位修改；頂層故事段可逐段隱藏 | 四段品牌故事不能新增同款或排序；理念段落／引言不能逐段新增、移除與排序 |
| 合作提案 | 固定文字／圖片可修改；詢問資料另由 WordPress 後台保存與檢視 | 合作方式卡、五步流程、場景卡、永續價值卡、SDG 標誌、售後服務卡無逐張完整 CRUD；表單欄位不應當成可任意複製的設計卡 |
| 飛熊日誌 | 正式文章、分類、精選圖片由 WordPress 原生文章 CRUD；三張靜態預告卡已從本地修正移除 | 原手稿以外的新增段落不提供；文章沒有精選圖片時仍需補圖，維持卡片完整 |
| 購買與服務 | 固定說明文字可修改 | 訂製／運送／保固子段與 FAQ 問答沒有區內逐筆新增、刪除與排序；目前只能隱藏整個頂層服務段 |
| 商店、購物車、會員 | 商品、訂單、會員及結帳依 WooCommerce／WordPress 管理 | 不屬於八個 `[bfnd_page]` 版面；交易與會員欄位不能由通用版面區塊任意複製或刪除 |

## 客戶可自由編輯的完成標準

1. 對手稿既有的**內容集合**使用與圖稿相符的原生文章資料：在所屬清單新增、檢視、修改、移到回收桶／還原；每筆設定標題、內文、精選圖片、分類與發布狀態。固定數量的手稿卡片不新增未畫出的項目。
2. 固定英雄區、單一 CTA 與表單外框保留版型控制；提供文字、圖片、顯示開關。未獲客戶修改手稿時，不新增另一段或改變位置。
3. 家具作品、生活木作作品、課程、日誌、商品繼續使用 WordPress／WooCommerce 既有內容類型，不在「網站版面」再造第二套重複資料。
4. 每頁主編輯區維持一行短代碼。後台逐筆操作需實測草稿／公開、前台位置與樣式、回收桶／還原、手機版、權限與 nonce；八頁及商務路由需回歸檢查。

目前不能向客戶宣稱「每個小區塊都有完整 CRUD」。
