# 飛熊入夢網站後台操作指南

更新日期：2026-10-06

本指南說明新版外掛與主題目前原始碼中的後台欄位。各段落的上線狀態以 `DEPLOYMENT.md` 為準；本機來源欄位不代表正式站已安裝。

## 設定品牌故事 YouTube 影片

1. 登入 WordPress，開啟「網站版面 → 品牌故事」。
2. 在「品牌影片｜YouTube」貼上一般 YouTube 影片網址、Shorts 網址或 `youtu.be` 分享網址，按「儲存此頁版面」。
3. 到品牌故事前台確認封面及播放控制。訪客按下播放後才載入播放器；影片不會自動播放。
4. 清空網址並儲存即可移除影片區塊。網址留白時，前台不顯示空白區、預告或假影片內容。

YouTube 網址可由有「編輯頁面」權限的使用者設定，不需編輯短代碼或程式碼。

## 新增一堂完整課程

1. 登入 WordPress，開啟「木作課程 → 新增木作課程」。
2. 在標題欄輸入課程名稱；在主要編輯區撰寫課程介紹，在摘要欄填寫列表卡片的短介紹。
3. 在右側「特色圖片」設定課程主圖。
4. 在「飛熊入夢作品資料」填寫：
   - 課程軌道：`level1`、`level2`、`level3`、`specialist` 或 `membership`。
   - 課程模式：`onsite` 或 `online`。
   - 課程特色、適合對象、學習內容、使用工具、完成成果、開課資訊、注意事項：一行一項。
   - 時數與程度標籤。正式資訊未定時留白，網站會隱藏空值。
   - WooCommerce 課程／會員方案商品：從已發布、已標記為課程商品的虛擬商品中選取。完成綁定後，課程售價直接讀 WooCommerce，不會拿課程舊顯示價格覆蓋商品售價。
   - 報名按鈕文字：單一商品留白時顯示「立即報名」；變化商品固定顯示「選擇梯次／方案」。未綁定可購買商品時固定導向課程詢問表單。
5. 在課程照片／簡章圖集將簡章排第一張，課程照片接續排序。圖片替代文字可在「媒體 → 媒體庫」編輯附件 ALT。
6. 按「儲存草稿」先預覽；核對課綱、金額、時數、梯次文字、商品連結及圖片後，再發布。

### 課程使用 WooCommerce 收款

1. 到「商品 → 新增商品」，為一堂課或一個會員方案建立專用商品。單一固定價格用「簡單商品」；要選開課梯次或 4／8／12 次方案，用「變化商品」，把每個梯次／方案設為變化項目並填各自售價與名額。
2. 在商品編輯頁「木作課程／會員方案商品」勾選收款項目並儲存。系統會自動設為虛擬商品，免收實體運費；並自一般商店商品列表隱藏，保留課程頁導入的購買入口。取消勾選後會恢復原商品目錄可見狀態。
3. 回到「木作課程」編輯頁，在「WooCommerce 課程／會員方案商品」選取剛建立的商品並更新課程。公開課程卡及內頁會讀取 WooCommerce 售價。
4. 單一商品按鈕會將課程加入購物車；變化商品會先開啟 Woo 商品頁供學員選梯次／方案，再加入購物車。購物車與結帳沿用 WooCommerce 既有付款方式、訂單、付款通知及管理員訂單紀錄。
5. 名額由 WooCommerce 商品／變化項目的庫存管理。課程購買紀錄保存在 WooCommerce 訂單，變化項目的梯次／方案會記在訂單商品明細；付款人姓名、Email、電話使用 WooCommerce 結帳資料。若由他人代報名，請在訂單備註填學員姓名。

### 線上課程付款後寄送 YouTube 連結

1. 編輯「木作課程」，確認「課程模式」為 `online`，在「線上課程 YouTube 連結」貼上 HTTPS 的 YouTube 影片網址並更新。
2. 為課程建立專用 WooCommerce 虛擬商品並綁定課程；確認該課程商品價格、綠界付款方式及結帳 Email 欄位都已設定。
3. WooCommerce 訂單完成付款後，系統會把連結寄到訂單 Email；每筆課程商品只自動寄一次。後台訂單備註會記錄郵件程序結果，`wp_mail()` 接受不代表收件匣已收到。
4. 若付款時尚未填影片連結或寄送失敗，先補好課程連結，再到訂單右側「訂單動作」選「重新寄送線上課程連結」。只允許已付款訂單送出。
5. YouTube 設為「私人」時，業主還要把學員的 Google 帳號加入觀看權限；單寄網址不會授權。設為「不公開」時，持有網址的人都可觀看，請業主按課程內容選擇適合的隱私設定。

不得把實體課程連到影片寄送流程；影片網址不會輸出在公開課程頁、商品目錄或訂單商品名稱中。

「開課資訊」欄只作補充文字；要讓學員選梯次，請用變化商品建立梯次選項。這會用 WooCommerce 訂單管理報名購買紀錄，不會另建學員名冊、候補清單或出席管理。正式商品及梯次價格需先確認後建立；不能用現有家具商品代收課程費用。

### 客戶課程價格與學習路徑（2026-10-05）

- LEVEL 1「木工基礎入門班」：6 小時，NT$ 3,680。
- LEVEL 2「木工實作養成」：12 小時，NT$ 6,280。
- LEVEL 3「自主製作養成」：18 小時，NT$ 7,800。
- 完整方案「木工基礎養成方案」：LEVEL 1 + LEVEL 2 + LEVEL 3，共 36 小時，優惠價 NT$ 15,800。客戶資料沒有提供方案原價，不要自行設定原價或特價欄位。
- 「自由創作會員」使用變化商品：4 次 NT$ 4,800、8 次 NT$ 8,800、12 次 NT$ 12,000；適合具備基礎能力、希望持續創作者。每次前 1 小時老師教學，並有技術指導與工坊設備使用。
- CNC 數位木工與磨刀實戰班分類為專項技能課程。本圖沒有提供 CNC 時數／售價，也沒有更新磨刀資訊；保留原有已核實磨刀資料，不替 CNC 填值。
- 梯次日期與名額尚未提供。變化商品要在收到實際日期、方案及名額後建立；不要用「待公告」梯次公開收款。
- 客戶圖稿的 Level 2／Level 3／完整方案照片尚未以可核實原始照片交付。新版建立的課程資料預設為私密，發布前請補入實際課程照片並逐頁預覽。

## 新增家具作品

1. 到「家具作品 → 新增家具作品」，設定中文標題、本文作品故事、摘要與右側特色圖片。
2. 在「作品系列」與「家具分類」選擇所屬分類。系列與品項分類是兩種獨立 taxonomy。
3. 填寫英文名稱、作品類型、木材／材質、參考尺寸、表面處理及製作方式。
4. 尺寸資料核實後才勾選「尺寸資料已核對，可以在網站顯示」。未勾選時前台不顯示來源尚未確認的數字；木種文字中的「待確認」會被前台清除，未知木種不會由系統猜填。
5. 圖集順序：第 1 張作主圖、第 2 張用於 STORY、第 3 張起最多顯示 6 張 DETAILS。相關作品 ID 依順序以逗號分隔。
6. 儲存草稿預覽，再發布。

### 木材與尺寸選項（本機來源 0.5.35；正式站待更新）

- 在「可選木材／材質」與「可選尺寸」欄位中，每行輸入一個已確認可提供的選項；行順序就是前台顯示順序。新增、刪除或移動一行即可管理選項。
- 尺寸選項只有在勾選「尺寸資料已核對，可以在網站顯示」後才會公開。沒有設定選項時，作品頁維持原本的材質／參考尺寸文字，不顯示空選擇器。
- 客戶從作品頁選好規格後，會帶到合作詢價表單；後台詢問紀錄會保存作品、選擇的材質與尺寸。送出時會再次核對選項仍屬於該作品，改動或無效的選項不會被當成有效規格保存。
- 此功能走詢價流程，沒有連動售價、庫存、SKU、購物車或付款。需要討論特殊尺寸時，客戶仍可填寫「其他尺寸需求」。

### 商品分類與商品細節照片

- WooCommerce 原生商品分類仍在「商品 → 分類」管理。新版會將胡桃曲木桌、延展之境櫻桃木桌歸入「生活木作」，線鋸留在「手工具」；前台生活木作頁及木作學堂頁分別讀取對應分類的可購買商品。
- 商品主圖與細節照片在商品編輯頁「商品圖庫」新增、排序或移除。請只上傳實際商品照片；目前未提供的近拍先留空，不用情境圖補位。
- 目前已設定的自取地址可在「WooCommerce → 飛熊商務設定」修改。地址留白時，本地取貨方式會從結帳選項隱藏；填妥後再到「WooCommerce → 設定 → 運送」把本地取貨加入正確運送區域。宅配區域、運費及寄件資料仍要依業主確認內容設定。

## 新增商品

到「商品 → 新增商品」。WooCommerce 原生欄位可管理名稱、完整／短說明、一般價與特價、庫存、尺寸、運送類別、屬性（可用來記錄材質／木種）、主圖、商品圖庫與分類。出貨時間及商品專屬注意事項目前沒有新增的專用欄位，先放在商品說明中；運送方式與費用仍由全站配送設定和商品運送類別共同決定。新增後先儲存草稿並檢查公開頁，再發布。

## 發布日誌

到「文章 → 新增文章」，撰寫標題與內文，設定分類、特色圖片與圖片 ALT，先預覽後發布。日誌列表及首頁會讀取已發布文章。

## 訂單與會員

- 訂單：到「WooCommerce → 訂單」，檢查商品、帳單／配送資料、付款方式與付款狀態。只有確認金流或匯款實際到帳後才更新付款狀態。
- 未完成訂單：以 WooCommerce 訂單中的帳單 Email 聯絡顧客，並先確認付款狀態；本網站不會自行定時催款，聯繫時機與文案需由業主決定。
- 會員：到「使用者」檢視 WordPress 帳號；顧客訂單可由 WooCommerce 訂單頁查詢。重設密碼由會員登入頁的「忘記密碼」操作。
- 客戶及管理員 Email 是否實際抵達收件匣，需用專用測試地址逐筆驗證；後台設定已儲存不等於郵件已送達。

## 圖片

家具作品、課程及商品主圖可從媒體庫選取；多張圖可排序。ALT 文字在媒體庫附件詳細資料編輯。新版素材目錄含 WebP 衍生圖；WordPress 上傳圖片的尺寸產生與主機圖片最佳化外掛狀態，需在正式站另行核實。
