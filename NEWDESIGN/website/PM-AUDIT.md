## 圖像規則

- 客戶原始家具、托盤、課程海報只按實際內容呈現。
- 情境圖必須標明示意，不能充當真實工坊、合作案例、某件作品的細節或製作紀錄。
- `GPT Image 2.5` 已嘗試，服務回覆 `Requires basic plan or higher`，因此本輪未能用該模型新增情境圖。Logo 去背使用現有圖片編輯工具後已另存透明版本，原檔保留。

## 驗收狀態

0.2.3 已在正式站更新。12 個正式路由回應 HTTP 200，7 個舊 `/newdesign-*` 路由回應 HTTP 301 並轉至對應新頁；內容標記檢查通過。手機寬 390px 檢查首頁、學堂、品牌、合作、日誌、購物車、會員頁，沒有橫向溢出或破圖。合作場景圖片載入完成；家具頁載入更多、搜尋、分類、排序已在公開頁互動實測。此表將「圖稿示例」與「已確認可公開的真實資料」分開核對；缺少正式文章、實際場域及製作照片、線上課資料時，不能宣稱內容與圖稿逐像素完全一致。

## 2026-09-18 修正：版面 CRUD 改走左側專屬選單

- 客戶指定每個頁面本文只保留一行短代碼，逐區內容不在「頁面」編輯器操作。現已把八頁的原生區塊內容轉到 WordPress 左側「網站版面」選單，每頁有獨立的文字、媒體庫圖片與區塊顯示設定。
- 轉換回報 8 成功、0 失敗；總覽八頁皆為「版型已連接」。前台版型沿用現有主題與頁面 ID；生活木作的設定頁修改、儲存、前台顯示、還原完成實測。媒體庫選擇器可開啟。
- Chrome 核對生活木作的頁面主編輯區只有一個短代碼區塊，內容為 `[bfnd_page key="lifestyle"]`。其餘七頁以總覽的單行短代碼檢查確認；前台 12 個正式路由 HTTP 200、19 個舊網址 HTTP 301。
- 家具作品、生活木作作品、木作課程由各自的 WordPress 文章型態清單 CRUD；飛熊日誌由原生「文章／分類」CRUD。版面設定不處理付款、訂單或個資欄位。
