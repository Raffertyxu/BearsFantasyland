## 資料安全邊界與 0.2.7 修正（2026-09-17）

- 金流、物流與訂單維持 WooCommerce 和已安裝的綠界 WooCommerce 外掛處理；NEWDESIGN 只提供版面，未加入自訂金流 API、轉接服務、REST 路由或前台金鑰。綠界收款與物流總開關仍關閉，未做真實交易。
- 詢問表單使用 WordPress 既有 `admin-post.php` 入口、nonce、私密自訂文章類型及 `wp_mail()`。WordPress 核心沒有現成的前台聯絡表單，因此表單驗證與寫入仍有少量本站 PHP 處理程式；它沒有建立獨立端口或第三方中轉。
- 0.2.6 的表單附件曾透過媒體庫儲存，產生可直接開啟的公開網址，即使詢問文章是私密也無法保護檔案。0.2.7 移除前台附件欄位；舊版表單若送出檔案，後端回應 HTTP 400，且不建立詢問。歷史兩筆詢問皆為系統測試，其中一筆的附件是公開使用的 `logo.png`，不是客戶個資；另一筆沒有附件。
- 新通知信只含 WordPress 後台查看連結，不再複製姓名、聯絡方式、詢問內容或附件網址到郵件。表單提醒訪客不要輸入身分證、付款資料等敏感資訊。
- 正式站首頁、合作提案、購物車、結帳與會員頁均回應 HTTP 200 並載入 0.2.7；合作表單不再有檔案欄位。匿名檔案送出測試回應 HTTP 400；正常虛構資料送出回應 HTTP 302，後台建立私密詢問 `1554`，`wp_mail()` 回報接受。是否真正送達管理員信箱仍需核對信箱。
- 靜態掃描未在 NEWDESIGN PHP／JS 找到金流介接金鑰常值或自訂 REST／AJAX 路由；抽查公開頁 HTML 未見 `HashKey`、`HashIV`、`MerchantID` 等欄位。此結果不等於已審計綠界外掛、WordPress 資料庫、主機檔案與備份。介接金鑰在外掛設定中的儲存方式及主機／備份存取權仍需另行核對。
- 外掛頁另顯示一個位於 `wp-content/mu-plugins` 的強制使用檔案 `customize-controlsse.php`，無描述；後台原生外掛編輯器無法開啟其內容。名稱本身不能證明惡意，但它會自動執行且無法由一般外掛清單停用，需由主機檔案管理員檢視來源、內容及建立時間。在查明前，不能宣稱全站程式碼已完成資安審計；綠界收款目前仍保持關閉。
